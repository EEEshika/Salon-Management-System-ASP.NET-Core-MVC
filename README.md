# Salon Management System (ASP.NET Core MVC)

## Overview

Salon Management System is a web-based application developed using ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server. The system streamlines salon operations by managing customers, appointments, staff, services, and payments through a centralized platform.

## Features

* User Authentication & Authorization
* Customer Management
* Staff Management
* Service Management
* Appointment Scheduling
* Payment Tracking
* Dashboard Overview
* CRUD Operations
* Responsive User Interface

## Technologies Used

* ASP.NET Core MVC
* C#
* Entity Framework Core
* SQL Server
* HTML5
* CSS3
* JavaScript
* Git & GitHub

## Architecture

The project follows a layered architecture:

* Presentation Layer (MVC)
* Business Logic Layer (BAL)
* Data Access Layer (DAL)
